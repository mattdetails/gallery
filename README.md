# Graphyte Gallery

Tools, templates and design experiments from [Graphyte](https://graphytedesign.com), a small web studio. Each one started as a working page built with Claude, and what's here is a static HTML snapshot of it.

Open `index.html` for the gallery, or go straight to any folder's `index.html`. A few features that needed a live claude.ai account are switched off or run on example data: downloads in the Hex Generator and Post Maker, the Pricing Calculator's settings, and saving in the Client View and Recipe Box.

Recipe Box photos keep their original credits and licences, which are shown on each recipe.
